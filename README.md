#  Business Analytics Dashboard Suite – Excel

##  Project Overview

This project is a collection of interactive **Microsoft Excel dashboards** developed to analyze and visualize business data across three key areas:

1.  **Employee Performance & Attendance Analysis**
2.  **Customer Feedback & Service Analysis**
3.  **Financial Budget vs Actual Analysis**

The dashboards transform raw business data into interactive visual insights using **Pivot Tables, Pivot Charts, slicers, KPIs, trend analysis, and data visualization techniques**.

The project demonstrates practical skills in **data analysis, business intelligence, dashboard development, KPI tracking, and decision-support reporting** using Microsoft Excel.

---

## Objectives

- Transform raw datasets into meaningful business insights.
- Build interactive and user-friendly Excel dashboards.
- Track important business KPIs and performance indicators.
- Identify trends, variations, and potential problem areas.
- Enable users to filter and explore data dynamically.
- Support data-driven business decision-making.
